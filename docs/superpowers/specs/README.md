# V5 Superpowers Specs

These files contain approved architecture/design decisions accumulated over the project. They are not all equally current.

Before using a dated spec, read:

1. `/PROJECT_MANDATE.md`
2. `/docs/superpowers/CURRENT_ARCHITECTURE.md`
3. `/docs/superpowers/SUPERSESSION_MAP.md`

The current architecture contract supersedes older implementation assumptions when later merged work changed them. Dated specs remain valuable for rationale, detailed contracts and historical decisions, but must not be used to resurrect superseded production behavior.

The consolidation spec `2026-09-15-current-production-architecture.md` summarizes the currently protected production architecture. Inspect current `main` code/workflows and production artifacts before concluding that an older spec describes the live implementation.
