# Tennis Quant Lab V5 — Superpowers Documentation Index

Before using any spec, plan, or implementation document in this directory, read the repository-root [`PROJECT_MANDATE.md`](../../PROJECT_MANDATE.md).

The governing order is:

1. `PROJECT_MANDATE.md` — highest-level product and engineering acceptance contract.
2. `docs/superpowers/specs/` — approved architecture and behavior specifications.
3. `docs/superpowers/plans/` — implementation plans for approved specifications.
4. Production code/workflows — implementation of the above.
5. Experiments/local fixes — must not override the mandate or approved architecture.

All work should continuously feed back to the same target:

**hands-off operation + durable out-of-sample edge + sellable MVP**.

A local fix is allowed when appropriate, but it must be checked against the full production system before being considered complete.
