# Independent audit of the 2026-10-31 to 2026-11-03 research results

Date: 2026-11-03. The user challenged the "no edge" verdicts as possibly biased. A separate agent,
which had not written the code, re-checked seven tests for errors that would hide an edge and
computed each test's minimum detectable effect (MDE: the smallest true effect with about 80% power
at 5% significance). Its check scripts are in the session scratchpad; no repo code was changed by
the audit.

## Verified correct

Orientation, residual signs and joins in all seven tests: no sign error that hides an edge.

## Errors found (all corrected on 2026-11-03)

1. **The Kaggle "Betfair" price is not a Betfair Exchange price.**
   - 41% of odds between 2 and 3 sit on odd cents, which the exchange price ladder does not allow
     (it moves in 0.02 steps there).
   - The median overround is 3.2%.
   - So it is a sportsbook price, and the 2% exchange commission charged on top of it in every
     money test double-counted costs (about 1 return point). It is removed everywhere, and the price
     is now described as a sportsbook close.
2. **Retirement write-up:** the retire-again rate was compared with the wrong base rate. Recently
   retired players retire again about 1.6 times as often, not less often. Corrected in
   `2026-11-03-retirement-risk.md`.
3. **Coverage gaps:**
   - The Challenger history has no entry data, and no qualifying rounds in either source, so the
     qualifier and wildcard flags cannot be built for Challengers. They are now unknown there, not
     zero.
   - 85% of Challengers had no indoor flag in the weather test.
   - The defending flag needs an exact event-name match with last year.
4. **Verdict wording was stronger than the evidence.** "Closed" and "nothing" were often really
   "cannot detect below 4-7 points". Revised labels are below.
5. Point DNA write-up: its headline table and betting example are v1 numbers; v2 is in
   `research_tests/point_dna/results_v2.json`.

The bootstraps resample matches, not players, so ranges are somewhat too narrow. This errs toward
false positives, not toward hiding edges.

## What changed in the process

Every negative result now reports its MDE and one of these labels: confirmed / candidate /
inconclusive below X / ruled out above X. Results that change a decision get an independent
audit before they are reported as settled.
