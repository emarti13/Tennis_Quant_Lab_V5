# From 5 games to the end of the set: failed serve-outs (2026-11-18)

**Status:** exploratory. Historical data from before 2026-11-01.

**Why:** the user disputed my claim that "a failed serve-out moves the match price only a few points". He asked for every set to be reviewed from the first time a player reaches 5 games.

**Test:** `research_tests/pressure/run_five_zone.py`, design pushed (`00498c5`) before the run.

**Data:** Match Charting Project, point by point:

| tour | failed serve-outs | matches |
|---|---|---|
| WTA | 2,018 | 1,532 |
| ATP | 2,161 | 1,759 |

A failed serve-out is a server at 5-x (x ≤ 4) or 6-5 who gets broken.

**Expected values:** both players' share of serve points won over the whole match, with points treated as independent (`research_kit.inplay`).

## 1. How far a fair match price drops when the serve-out fails

Drop for the server, in points (median and quartiles):

| situation | WTA | ATP |
|---|---|---|
| deciding set, serving for the match | **23.6** (7.8–30.3); 87 → 67 on average | **32.6** (20.9–39.0); 91 → 62 |
| first set | 4.7 (1.0–11.8) | 8.2 (1.9–14.4) |
| middle set | 6.4 (3.1–11.0) | 8.5 (2.5–14.2) |
| middle set, serving for the match (a set up) | 1.6 (0.2–7.4) | 4.1 (0.3–12.4) |

My statement was **wrong** for the deciding set, where the drop is a quarter to a third of the whole price. It held only when the server is a set up.

## Labels

- **WTA momentum after a failed serve-out: candidate.** Compared with what both players' serve that day predicts:
  - the breaker holds the next game 6.7 points more often;
  - the broken server wins the set 4.0 points less often.

  This is what the user described: the set turns, and the player who was behind keeps winning games.
- **ATP:** a smaller hold boost (+2.3) and no effect on the set.
- **Together with `2026-11-18-serve-out-pressure.md`:** WTA servers under-hold when serving for the match (−2.2 points beyond the leading control), and lose more sets than expected after being broken.
